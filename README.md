# Deadline Collision Detector

 C project that helps students keep track of their assignments, lab records, tests and exams. It stores deadlines and checks if multiple tasks are scheduled too close to each other.

## Features

* Add new deadlines
* View all saved deadlines
* Search deadlines by date or name
* Edit and delete deadlines
* Check for multiple deadlines on the same day
* Find three or more deadlines within 24 hours
* View upcoming deadlines
* Sort deadlines based on urgency
* Save and load deadlines using file handling

## Concepts Used

* Structures
* Linked Lists
* Binary Search Trees
* Min Heap
* Sorting and Searching
* File Handling
* Dynamic Memory Allocation

## How to Run

Compile the files using GCC:

```bash
gcc main.c task_management.c deadline_analysis.c collision_storage.c -o deadline_detector
```

Run the program:

```bash
./deadline_detector
```
